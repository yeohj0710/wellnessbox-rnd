# TIPS Evaluator UI Overhaul Implementation Plan

**Goal:** 연구기관 평가자가 KPI별 측정 대상, 판정 기준, 저장 결과와 직접 실행 경로를 한 화면에서 확인하고 재현할 수 있도록 `/tips` 평가 UI를 개편한다.

**Architecture:** 기존 7단계 실행 흐름과 API는 유지하고, 연구 개요에 KPI 평가 매트릭스를 추가한다. 각 KPI는 실제 실행 가능한 단계로 연결하며, 단계 설명은 중첩 모달 대신 우측 설명 패널로 제공한다. 공통 버튼 높이와 여백은 평가 도구에 맞게 축소한다.

**Tech Stack:** Next.js, React, TypeScript, CSS Modules

---

### Task 1: KPI 평가 매트릭스

- [ ] KPI 1~7의 측정 대상, 표본, 판정 기준, 저장 결과를 표시한다.
- [ ] 각 KPI를 관련 직접 평가 단계 또는 산출물 확인 단계로 연결한다.
- [ ] 추천 모델 일치율과 Agent 성능 지표를 분리해 표시한다.

### Task 2: 평가 화면 문구와 상호작용

- [ ] 개발 과정 설명처럼 보이는 문구를 평가기관용 문체로 교체한다.
- [ ] 단계 설명 중첩 모달을 우측 설명 패널로 변경한다.
- [ ] 구조도 노드의 입력, 출력, 현재 상태와 평가 진입 기능을 유지한다.

### Task 3: 화면 밀도와 검증

- [ ] 공통 실행 버튼, 재계산 버튼, 하단 탐색 버튼의 높이와 여백을 축소한다.
- [ ] 데스크톱과 모바일에서 모달, 스크롤, 고정 하단 버튼을 브라우저 검수한다.
- [ ] TIPS QA, TypeScript, 인코딩, diff 검사를 통과시킨다.
- [ ] 관련 파일만 커밋하고 main에 push한 뒤 Vercel 프로덕션을 확인한다.
