# 지정 로컬 연구 운영 환경

## 어떤 환경을 운영 환경으로 인정하는가

`wellnessbox-local-research-pc`는 웰니스박스와 R&D API를 같은 컴퓨터에서 필요할 때만 실행하는 지정 연구 운영 환경이다. 상시 서버나 유료 클라우드를 사용하지 않는다. `research-server-start.cmd`로 시작하고 `research-server-stop.cmd`로 종료한 세션만 운영 영수증 수집 대상이다.

## 어떤 사실을 운영 증거로 남기는가

수집기는 세션 시작과 종료 시각, 두 저장소의 소스 커밋, 로컬 서버 주소, 실제 SQLite 테이블의 시작·종료 건수 차이, 관찰된 사용 행동, 행동에 연결된 OP 번호를 JSON으로 남긴다. 테이블 건수가 늘지 않은 행동은 관찰됐다고 기록하지 않는다. 따라서 서버를 켜기만 한 세션은 설문·추천·후속평가 증거가 되지 않는다.

## 어디에 저장하고 어떻게 서명하는가

실제 영수증은 `data/original_plan/final_session/operational_receipts/`에 저장한다. H-006에서 만든 Ed25519 키가 있으면 수집기가 저장 내용을 자동으로 서명한다. 키가 없으면 내용 지문만 남기며, H-007은 서명 없는 영수증을 OPERATED 승격 근거로 받아들이지 않는다. 리허설은 임시 폴더에만 쓰고 실제 영수증 경로를 건드리지 않는다.

## 어떤 경우에 OPERATED로 올리는가

`data/original_plan/operational_action_coverage_v1.json`은 41개 요구사항을 실제 사용 행동에 연결한다. H-007은 유효한 서명, 지정 환경 ID, 실제 세션 표시, 양수인 테이블 변화가 모두 확인된 영수증만 누적한다. 외부 검증이 필요한 OP-039는 이 운영 영수증으로 대체하지 않는다.
