# OP-037 단위 변환 후 상한을 비교하고 불명확하면 보수적으로 차단한다.

manifest의 정본 증거 `wellnessbox-rnd/data/original_plan/evidence/op037_op038_dose_limit_rule_metadata_smoke_v1.json`은 단위 변환이 끝난 완전한 합계와 변환할 수 없는 입력을 다른 결과로 기록한다. 비타민 C 1g과 1.2g은 2,200mg으로 환산돼 상한 2,000mg을 넘고 전체 차단 상태(`blocked`)가 된다.

## 서로 다른 단위를 그대로 더하면 안 되는 이유

1g과 500mg을 숫자만 더하면 501이라는 잘못된 총량이 된다. 비타민 D처럼 질량과 국제단위(IU)를 함께 쓰는 성분은 단위 종류가 같지 않아도 정해진 성분별 환산식이 필요하다. 반대로 환산 근거가 없는 IU와 mg을 임의 비율로 바꾸면 안전 판정 자체가 거짓이 된다. 그래서 시스템은 지원하는 변환만 계산하고, 나머지는 “자료가 불완전하다”는 별도 사유로 남긴다.

`wellnessbox-rnd/src/wellnessbox_rnd/safety/service.py`는 ng, mcg, mg, g를 mg 기준 비율로 변환한다. 비타민 D3에 한해서는 1mcg를 40IU로 바꾸는 양방향 계산을 둔다. 같은 단위는 그대로 사용하고, 이 두 범위에 들지 않으면 변환 결과를 만들지 않는다. 상한 단위는 `wellnessbox-rnd/data/rules/safety_rules.json`에 성분별로 고정돼 있으며 비타민 D3 4,000IU, 비타민 C 2,000mg, 아연 40mg, 마그네슘 글리시네이트 350mg, 칼슘 시트레이트 2,000mg이다.

## 완전한 초과와 불명확한 입력을 다르게 처리한다

모든 제품의 용량을 같은 단위로 바꿀 수 있고 합계가 상한보다 크면 규칙 사유는 `upper_limit_exceeded`가 된다. 해당 성분을 제외하고 전체 차단 등급을 적용하므로 요청 전체 상태도 `blocked`다. 완전한 합계가 상한 이하라면 용량 규칙은 발생하지 않는다.

부분 용량, 호환되지 않는 단위, 범위나 복용 횟수가 섞인 문구는 `dose_evidence_incomplete`로 처리한다. 이때 성분은 후보에서 보수적으로 제외하지만 규칙은 정보 등급(`info`)이므로 전체 요청 상태는 `ok`일 수 있다. 즉 이 구현에서 “불명확하면 차단”은 불명확한 성분의 추천 제외를 뜻하며 모든 요청의 전면 중단을 뜻하지 않는다. 용량 입력이 아예 선택 사항으로 빠진 경우에는 상한을 평가했다고 주장하지 않고 용량 규칙 자체를 만들지 않는다.

## 오판하기 쉬운 입력을 시험한 결과

정본 실행 결과는 완전한 초과 2,200mg, 완전한 이하 1,500mg, 무용량 비타민 D, 한 제품 용량이 빠진 비타민 D, 비타민 C에 잘못 붙은 IU, `1000 mg - 2500 mg` 범위를 비교한다. 초과 사례만 전체 차단 등급이 되고, 부분·비호환·범위 사례는 불완전 사유와 성분 제외를 남긴다. 모든 결과는 `2026-07-16T00:00:00+00:00` 한 시각을 사용해 실행 시각 차이로 자료가 흔들리지 않게 했다.

`wellnessbox-rnd/tests/test_medication_supplement_input_contracts.py`는 g·mg·mcg·ng 합산과 비타민 D의 mcg/IU 변환을 확인한다. `twice daily`, `2 x`, `bid`, 범위 표기처럼 일일 총량으로 단정할 수 없는 문자열은 숫자가 보여도 불완전으로 남는다. `wellnessbox-rnd/tests/test_runtime_knowledge_db.py`는 구조화 상한, 단위와 양수가 런타임 자료에 존재하고 초과 결과가 규칙 버전을 포함하는지 시험한다.

초기 오류 로그는 `확인되지 않음`으로 남긴다. 조사 범위는 용량 입력 형식, 변환 함수, 상한 규칙, 두 집중 시험 파일, 정본 결과 생성기와 JSON이다. 따라서 실제로 어떤 순서로 입력 해석기를 고쳤는지는 쓰지 않았고, 현재 방어하는 실패 입력과 반환 결과만 기술했다.

## 완료 단계와 임상 근거의 한계

지원 단위의 결정론적 환산, 상한 비교, 불명확 입력의 성분 제외를 로컬에서 재현했으므로 OP-037은 `IMPLEMENTED`다. 모든 IU 환산을 지원하지 않으며 비타민 D3 이외의 성분별 변환표도 없다. 더 중요한 한계는 현재 용량 상한 규칙의 `reference_ids`와 `claim_ids`가 비어 있다는 점이다. 숫자가 코드와 시험에서 일관된다는 사실은 외부 임상 기준의 최신성과 적용 대상을 검증하지 않는다. 실제 상품 라벨과 운영 복용 기록도 관측하지 않았으므로 더 높은 증거 단계는 남겨 둔다.
