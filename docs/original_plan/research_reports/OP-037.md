# OP-037 단위 변환 후 상한을 비교하고 불명확하면 보수적으로 차단한다.

## 이 요구가 해결하는 문제

핵심 요구는 다음과 같다. 단위 변환 후 상한을 비교하고 불명확하면 보수적으로 차단한다. 안전 규칙은 추천 점수보다 먼저 적용돼야 하며, 차단 결과를 뒤 단계가 되돌릴 수 없어야 한다. 기준 요구 목록과 등록 증거를 대조했으며, 현재 단계는 `IMPLEMENTED`다. 이 보고서는 코드와 테스트가 보여 주는 범위만 다룬다. 실제 사용자 자료나 외부 전문가 판단이 없는 부분을 운영 완료로 넓혀 말하지 않는다.

## 구현 근거를 어떻게 읽었는가

첫 구현 근거는 `wellnessbox-rnd/src/wellnessbox_rnd/safety/service.py`다. 파일을 직접 읽었을 때 크기는 27,853바이트였고, 내용 지문인 SHA-256 앞 12자리는 `9d257c8bfb44`였다. 이 경로의 최근 관련 커밋은 `8b5f6dd`이다. 파일명만 인용하지 않고 현재 저장소의 실제 내용을 읽어 요구 제목과 책임 범위를 맞췄다. 등록된 나머지 구현 경로도 모두 열 수 있는지와 내용 지문을 함께 계산했다.

## 어떤 테스트와 증거가 남아 있는가

자동 검증 근거로 `wellnessbox-rnd/tests/test_medication_supplement_input_contracts.py`를 읽었다. 이 파일은 27,604바이트이며 SHA-256 앞 12자리는 `4dcdff4f4943`다. 최근 관련 커밋은 `94b0374`이다. 기준 감사는 이 경로가 존재하는지만 보지 않고 등록된 원본 내용과 현재 파일의 일치 여부도 확인한다. 따라서 이후 코드가 바뀌면 테스트와 기준 증거를 함께 갱신해야 같은 주장을 유지할 수 있다.

## 완료 단계와 한계

`IMPLEMENTED`는 코드와 자동 검증을 저장소에서 재현할 수 있다는 뜻이다. 서비스 운영과 사람의 실제 사용까지 증명하지는 않는다. 이 보고서는 증거 경로, 파일 내용, 커밋 이력을 현재 시점에서 다시 읽어 작성했다. 약사 승인, 독립 외부 검증, 공개 배포가 필요한 주장은 별도 사람 일 원장과 운영 증거에서 다룬다. 나중에 단계가 바뀌면 기준 목록을 먼저 수정하고 감사기를 다시 실행해야 한다.
