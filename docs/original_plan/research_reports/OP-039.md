# OP-039 hard false negative 0을 고위험 frozen eval로 검증한다.

## 이 요구가 해결하는 문제

핵심 요구는 다음과 같다. hard false negative 0을 고위험 frozen eval로 검증한다. 안전 규칙은 추천 점수보다 먼저 적용돼야 하며, 차단 결과를 뒤 단계가 되돌릴 수 없어야 한다. 기준 요구 목록과 등록 증거를 대조했으며, 현재 단계는 `미주장`다. 이 보고서는 코드와 테스트가 보여 주는 범위만 다룬다. 실제 사용자 자료나 외부 전문가 판단이 없는 부분을 운영 완료로 넓혀 말하지 않는다.

## 구현 근거를 어떻게 읽었는가

첫 구현 근거는 `wellnessbox-rnd/src/wellnessbox_rnd/evals/external_high_risk_safety.py`다. 파일을 직접 읽었을 때 크기는 21,322바이트였고, 내용 지문인 SHA-256 앞 12자리는 `77ff0f05e33e`였다. 이 경로의 최근 관련 커밋은 `e830c7d`이다. 파일명만 인용하지 않고 현재 저장소의 실제 내용을 읽어 요구 제목과 책임 범위를 맞췄다. 등록된 나머지 구현 경로도 모두 열 수 있는지와 내용 지문을 함께 계산했다.

## 어떤 테스트와 증거가 남아 있는가

자동 검증 근거로 `wellnessbox-rnd/tests/test_external_high_risk_safety_eval.py`를 읽었다. 이 파일은 15,819바이트이며 SHA-256 앞 12자리는 `a9e0cdb11275`다. 최근 관련 커밋은 `22aca5e`이다. 기준 감사는 이 경로가 존재하는지만 보지 않고 등록된 원본 내용과 현재 파일의 일치 여부도 확인한다. 따라서 이후 코드가 바뀌면 테스트와 기준 증거를 함께 갱신해야 같은 주장을 유지할 수 있다.

## 완료 단계와 한계

이 요구는 프로젝트 소속 면허 약사 권혁찬의 실제 검토가 필요한 항목이어서 완료 단계를 주장하지 않는다. 권혁찬은 시스템 구현과 AI 초안 검토에 참여하지 않았지만 과제 공동연구원이므로 `independent_of_implementation_team=false`다. 따라서 검토 성격은 이해관계 없는 제3자 독립 검증이 아니라 프로젝트 소속 면허 약사의 전문가 안전 검토다.

`wellnessbox-rnd/data/original_plan/final_session/external_validation/op039_external_validation.json`에는 10개 사례가 모두 `pending`으로 남아 있다. 오너 여형준의 기존 판정은 자기검토로 보존했으며 OP-039 충족 근거에서는 제외했다. 권혁찬이 콘솔에서 각 사례를 직접 판정하고 실제 자격 확인 방법을 기록한 뒤 서명하기 전에는 감사의 외부 검증 부족 1건이 정상이다.
