# OP-049 추천 모델과 deterministic baseline 차이를 replay에서 비교한다.

등록된 결과 파일 `wellnessbox-rnd/data/original_plan/evidence/op049_op050_replay_product_candidates_smoke_v1.json`은 고정 평가 세트 256건을 기준 추천과 학습 재정렬로 각각 실행한 차이를 보존한다. 같은 입력을 두 경로로 다시 실행하는 비교(replay)가 구현됐으므로 OP-049는 `IMPLEMENTED`다.

## 최종 점수 하나가 아니라 변화 위치를 보는 이유

학습 모델을 붙였다는 사실만으로 개선을 판단할 수 없다. 몇 건에 적용됐는지, 후보 순서가 어디서 바뀌었는지, 안전 상태나 다음 행동까지 달라졌는지를 함께 봐야 한다. 특히 추천 순위만 조정하려던 모델이 안전 요약이나 `STOP_AND_ESCALATE` 같은 후속 행동을 바꾸면 설계 경계를 넘은 것이다. 이 비교는 성능 우열보다 먼저 학습 기능의 영향 범위를 측정한다.

비교에 사용한 `wellnessbox-rnd/data/original_plan/fixtures/op049_learned_replay_artifact_v1.json`은 운영 모델이 아니다. `baseline_candidate::vitamin_c` 특성 하나와 가중치 0.2를 가진 재생 전용 시험 파일이다. 단순한 파일을 쓴 이유는 변화가 생긴 원인을 숨기지 않고 비교기 자체를 검증하기 위해서다.

## 같은 사례를 두 경로로 실행한 방식

`wellnessbox-rnd/src/wellnessbox_rnd/evals/recommendation_replay_compare.py`는 `data/frozen_eval/frozen_eval_v1.jsonl`의 각 사례를 두 번 처리한다. 첫 실행은 기준 추천이고, 두 번째 실행은 학습 재정렬을 켠 추천이다. 두 응답에서 후보 키, 순위, 총점, 학습 가산점을 뽑아 추가·제거·순위 변경을 계산한다.

안전 비교는 상태 문자열 하나만 보지 않는다. 적용 시각을 제외한 안전 요약 전체, 상위 안전 표지, 안전 근거 전체를 정렬된 JSON으로 바꿔 비교한다. 응답 상태와 다음 행동도 별도 항목이다. 따라서 “추천 순위는 바뀌었지만 안전 판단은 같았다”와 “안전 판단까지 달라졌다”를 구분할 수 있다.

보고서 스키마는 집계 숫자를 사례 목록에서 다시 계산한다. 학습이 적용되지 않은 사례가 선택 변경을 주장하면 거부하고, 추가·제거 성분이나 순위 차이가 실제 두 후보 목록과 맞지 않아도 실패한다. 평가 결과를 손으로 고쳐 좋은 숫자만 남기기 어렵게 만든 장치다.

## 256건 재생에서 관측된 변화

기준 증거에서 256건 중 12건에 학습 재정렬이 적용됐고 244건은 적용 조건을 충족하지 않아 기준 결과를 사용했다. 선택 순서가 달라진 사례는 4건, 순위 또는 점수가 달라진 사례는 5건이었다. 응답 상태, 다음 행동, 안전 자료가 달라진 사례는 모두 0건이었다. 적용 사례 중 `eval-097`, `eval-164`, `eval-187`, `eval-188`에서는 비타민 C와 비타민 D3의 순서가 바뀌었다. `eval-018`은 선택 순서는 같고 비타민 C 점수만 3.0 올라갔다.

`wellnessbox-rnd/tests/test_recommendation_replay_product_candidates.py`는 256건 전부가 보고서에 들어가는지와 집계값을 확인한다. 안전 요약의 중복 성분을 바꾸거나 안전 근거를 하나 추가하면 안전 지문이 달라지는 시험도 있다. 선택 변경 건수를 1 늘리거나 상태 이름을 임의 문자열로 바꾸면 Pydantic 검증이 실패한다. 현재 이 시험을 포함한 집중 검증은 통과했다.

## 결과를 해석할 때 지켜야 할 한계

OP-049의 증거 단계는 `IMPLEMENTED`다. 256건 고정 입력에서 두 추천 경로의 차이를 재현했지만, 학습 모델이 실제 효과를 높였다고 증명하지 않았다. 12건에서 복귀 상태가 0건이라는 결과도 장애 복귀가 불필요하다는 뜻이 아니다. 이 실행에서는 재생 전용 파일이 정상이라 복귀 조건이 발생하지 않았을 뿐이며, 파일 장애는 OP-048의 별도 시험이 다룬다.

평가 세트는 실제 운영 사용자 집단이 아니고, 비타민 C 한 특성의 시험 파일은 일반화 성능을 보여 주지 않는다. 비교기, 고정 평가 세트, 재생 전용 모델 파일과 기준 증거 안에서는 production 트래픽, 사용자 선택, 복용 전후 결과의 연결이 `확인되지 않음`이다. 운영 단계로 올리려면 배포된 모델과 기준 로직을 같은 운영 기록에서 재생하고, 안전 불변식과 실제 결과 차이를 함께 보존해야 한다.
