# OP-108 — 실제 판매 상품 후보와 추천 결과 연결

추천 라우트는 R&D 성분 추천을 WellnessBox 판매 상품 카탈로그에 연결한다. canonical QA는 재고가 있는 약국 상품의 성분, 함량, 가격, 제형을 읽고 8개 서비스 성분에 실제 상품 ID를 붙였다. 후보 조합은 비용과 상품 수 제한을 지키며, 안전 제외 성분은 다시 들어오지 않는다. 재고가 바뀌면 같은 최적화 입력으로 안전한 대체 조합을 다시 계산한다.

잘못된 상품 카탈로그와 모호한 함량은 502로 닫힌다. 상품을 찾지 못하면 ID를 만들지 않고 `NO_MATCH`를 표시한다. 사용자 승인 전에는 카트 저장, 주문, 결제 변경이 없다. 요구 단계 `OPERATED`에 비해 이번 주장은 `INTEGRATED`다. 고정 판매 상품 fixture와 서비스 라우트 계약을 검증했지만 실제 운영 재고와 주문은 변경하지 않았다.
