# OP-120 독립 최종 감사가 100% 완료를 증명한 뒤 전체 목표를 완료 처리한다.

## 요구사항과 실제 결과

OP-120은 독립 최종 감사가 OP-001부터 OP-120까지 모든 완료 조건을 직접 증명한 뒤에만 전체 목표를 완료하도록 요구한다. 이번 구현은 완료 조건을 자동으로 수집하고 하나라도 부족하면 `BLOCKED`를 반환하는 최종 감사기를 추가했다. 현재 결과는 `BLOCKED`이며 전체 목표는 완료되지 않았다.

## 해결한 문제와 재사용한 경로

기존 manifest 감사기는 요구사항 120개, 증거 파일, 원문 해시와 Git 추적 여부를 검사하지만 연구보고서 120개, 요구 단계 충족, 외부 검증, 최종 검증 영수증과 독립 검토 영수증을 하나의 완료 판정으로 묶지 않았다. 새 감사기는 기존 `original_plan_audit.py`와 manifest schema를 그대로 호출한다. 별도의 요구사항 목록이나 증거 체계를 만들지 않아 기존 감사 결과와 OP-120 판정이 갈라지는 문제를 막았다.

## 입력과 처리 계약

감사기는 기준 manifest, 두 저장소의 루트, 연구보고서 디렉터리와 정책 파일을 입력으로 받는다. 비외부 요구사항은 `IMPLEMENTED < INTEGRATED < OPERATED` 순서로 요구 단계와 주장 단계를 비교한다. `EXTERNAL` 요구사항은 같은 순서에 섞지 않고 실제 `EXTERNAL` 주장만 인정한다. 연구보고서는 정확한 `OP-NNN.md` 파일명, 최소 분량과 절 구조, 요구·검증·증거·완료 경계의 의미 범주, manifest 증거 경로 인용을 검사한다. 최종 검증 영수증과 독립 검토 영수증은 Git 추적, manifest 및 기준 감사 지문, 소스 커밋, 허용된 Ed25519 서명과 통과 상태가 모두 맞을 때만 인정한다.

## 실패 처리와 안전 경계

요구사항 수나 주장 수가 120이 아니거나, 요구 단계가 부족하거나, 외부 검증이 없거나, 보고서가 빠지거나, canonical evidence 감사가 실패하거나, 두 최종 영수증 중 하나가 없으면 감사기는 완료를 거부한다. 읽을 수 없거나 형식이 잘못된 영수증도 통과로 추정하지 않는다. 현재 정책은 영수증 경로를 `null`로 유지하므로 허위 완료 증거를 만들지 않는다.

## 검증 범위와 canonical evidence

고정 데이터셋은 요구사항 재고, 주장 재고, 비외부 단계 부족, 외부 검증, 보고서 수, 기준 증거, 최종 영수증, 완료 결정의 8개 사례를 검사한다. 현재 관측값은 요구사항 120개, 주장 119개, 비외부 단계 부족 43개, 외부 검증 부족 OP-039, 유효 보고서 120개와 누락 0개, 두 최종 영수증 미등록, 최종 상태 `BLOCKED`이다. 재생 스크립트는 커밋된 소스 파일과 작업 파일이 같을 때만 증거를 생성한다.

## 서비스 통합·운영·외부 검증 상태

OP-120 감사기와 최종 세션 콘솔은 R&D 저장소에서 실행할 수 있다. 서비스 저장소와 연결된 기존 증거는 기준 감사가 재검사한다. 그러나 43개 비외부 요구사항은 요구 단계에 못 미치고 OP-039의 외부 검증도 없다. 따라서 OP-120은 `IMPLEMENTED / PARTIAL`만 주장하며 `OPERATED`를 주장하지 않는다.

## 현재 한계와 완료 조건

남은 조건은 비외부 단계 부족 43개 해소, OP-039 외부 검증 등록, 전체 검증 영수증 등록, Critical 0·Important 0 독립 검토 영수증 등록이다. 연구보고서 120편은 모두 유효하다. 모든 조건을 동시에 충족하고 기준 감사가 계속 통과할 때만 감사 결과가 `READY`와 `goal_complete=true`로 바뀐다.

## 관련 구현과 검증 자산

핵심 구현은 `wellnessbox-rnd/src/wellnessbox_rnd/governance/final_completion_audit.py`와 `wellnessbox-rnd/src/wellnessbox_rnd/governance/final_session_console.py`다. 회귀 테스트는 `wellnessbox-rnd/tests/test_final_session_console.py`, 단일 실행기는 `wellnessbox-rnd/scripts/run_final_session_console.py`에 있다. 리허설 증거 `wellnessbox-rnd/data/original_plan/evidence/final_session_console_rehearsal_v1.json`은 H-001~H-007을 임시 자료로 처리한 뒤 `READY`에 도달했고 실제 원장·영수증 경로를 바꾸지 않았음을 기록한다.
