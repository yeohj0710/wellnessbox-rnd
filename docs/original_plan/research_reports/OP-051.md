# OP-051 PSQI, ISI, PSS-10 원점수 계산을 버전 고정한다.

manifest에 연결된 증거 `wellnessbox-rnd/data/original_plan/evidence/op051_op052_versioned_pro_scoring_smoke_v1.json`은 PSQI, ISI, PSS-10의 입력 개수, 점수 범위, 역채점 위치와 예시 원점수를 기록한다. 계산 규칙은 `2026-07-17.1` 계약으로 고정됐으며 OP-051은 `IMPLEMENTED`다.

## 같은 응답이 항상 같은 원점수가 되어야 한다

복용 전후 효과를 비교하려면 설문 응답을 점수로 바꾸는 첫 단계가 흔들리지 않아야 한다. 문항 수나 역채점 위치가 코드마다 다르면 이후 Z 점수와 개선도도 달라진다. OP-051은 세 설문 도구의 원점수 계산만 다룬다. 시작 분포를 사용한 표준화와 백분위 계산은 같은 증거 파일에 함께 나오지만 OP-052 범위이므로 이 보고서의 완료 근거로 넓혀 쓰지 않는다.

PSQI는 수면의 질을 평가하는 Pittsburgh Sleep Quality Index, ISI는 불면 중증도 지수, PSS-10은 10문항 지각된 스트레스 척도다. 세 도구 모두 현재 계약에서는 점수가 낮을수록 문제 정도가 낮다고 해석한다. 다만 이 코드는 설문 문항을 제공하거나 임상 판정을 내리는 모듈이 아니라, 이미 점수화된 항목 값을 정해진 방식으로 합산하는 모듈이다.

## 세 도구의 계산 계약

`wellnessbox-rnd/data/contracts/pro_instrument_scoring_v1.json`은 세 정의를 한 파일에 둔다. PSQI는 0~3점인 파생 구성 점수 7개를 더해 0~21점을 만든다. 원 설문의 19개 자기보고 문항을 이 코드에서 재구성하지 않는다. ISI는 0~4점 항목 7개를 합해 0~28점이다. PSS-10은 0~4점 항목 10개를 받되 공식 순서의 4, 5, 7, 8번 값을 `4-응답값`으로 뒤집은 뒤 합산해 0~40점을 만든다.

각 정의에는 입력 종류, 항목 수, 항목 범위, 원점수 범위, 역채점 위치, 계산 버전, 출처 ID와 제한 문구가 있다. `wellnessbox-rnd/src/wellnessbox_rnd/metrics/pro_scoring.py`는 파일을 읽은 뒤 코드 안의 기준 정의와 완전히 같은지 다시 대조한다. 계약 파일에서 역채점 위치, 출처 URL, 제한 문구를 바꾸면 단순한 설정 변경으로 받아들이지 않고 계산 규칙 이탈로 거부한다.

입력은 Pydantic의 엄격한 정수로 받는다. 항목 개수가 다르거나 범위를 벗어난 값, 실수, 불리언, 예상하지 않은 필드는 통과하지 못한다. 함수에 이미 만들어진 모델 객체가 들어와도 경계에서 다시 검증한다. 원래 입력값, 역채점 뒤 값, 원점수, 점수 범위와 계산 버전을 결과에 함께 남겨 사후 대조가 가능하다.

## 예시 계산과 실패 경로 검증

기준 증거의 예시는 PSQI 구성 점수 `[1, 2, 1, 1, 1, 0, 1]`을 7점으로 계산한다. ISI `[2, 2, 1, 2, 1, 1, 1]`은 10점이다. PSS-10 `[2, 2, 2, 3, 3, 2, 3, 3, 2, 2]`는 역채점 뒤 `[2, 2, 2, 1, 1, 2, 1, 1, 2, 2]`가 되어 16점이다. 세 결과에는 각각 `psqi_component_sum_v1`, `isi_item_sum_v1`, `pss10_reverse_4_5_7_8_sum_v1`이 붙는다.

`wellnessbox-rnd/tests/test_versioned_pro_instrument_scoring.py`는 세 도구의 최솟값과 최댓값을 모두 확인한다. 6개짜리 PSQI, 8개짜리 ISI, 범위를 벗어난 PSS-10, `1.0`과 `True`가 섞인 입력은 실패해야 한다. PSS-10 역채점 위치를 하나 지운 계약, 가짜 출처 URL, “production 진단에 검증됐다”는 거짓 제한 문구도 거부한다. 이미 생성한 점수 객체의 원점수만 20으로 바꾸는 조작 역시 다음 공개 함수 경계에서 다시 걸러진다. 현재 이 파일을 포함한 집중 시험은 모두 통과했다.

## 구현 완료와 사용 전 확인 사항

OP-051의 단계는 `IMPLEMENTED`다. 세 원점수 계산과 계약 이탈 차단은 저장소에서 재현됐다. 그러나 기준 증거의 자료 등급은 `SYNTHETIC_OUTCOME_PROXY`이고, 서비스 연동과 production 사용은 모두 false다. 설문 문항 원문도 저장소 계약에 포함하지 않는다. 계약 파일, 계산 함수, 시험과 기준 증거를 조사한 결과 허가된 설문 화면과 실제 서비스 입력의 연결은 `확인되지 않음`이다. 실제 사용자의 문항 이해와 임상적 해석도 입증되지 않았다. 운영 적용 전에는 허가된 설문본, 입력 UI의 문항 순서, 실제 서비스가 전달하는 값과 계산 결과를 별도로 대조해야 한다.
