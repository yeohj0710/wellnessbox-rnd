# OP-117 브라우저 핵심 경로 연구보고서

## 결론

OP-117은 `IMPLEMENTED / PARTIAL`이다. 로컬 WellnessBox를 실제 Next.js 서버로 실행하고 Playwright Chromium에서 사용자 `/survey`, 약사 `/pharm` 인증 경계, 관리자 `/admin` 인증 경로를 재현했다. production 배포와 traffic은 검증하지 않았다.

## 검증 방법과 결과

사용자 화면은 `/survey` 본문 렌더링을 확인했다. 인증되지 않은 약사 접근은 `/pharm`에서 `/pharm-login`으로 이동하고 비밀번호 입력란을 표시했다. 관리자는 loop 전용 임시 비밀번호로 실제 `/api/verify-password`를 호출해 HTTP 200을 받은 뒤 `/admin` 본문을 렌더링했다. 임시 비밀번호는 evidence에 기록하지 않는다.

동결 데이터셋 `data/original_plan/op117_op118_browser_operational_evidence_cases_v1.json`은 OP-117/118 합계 8건이다. canonical evidence는 브라우저 3건의 실제 URL·가시성·로그인 상태와 두 저장소 소스 식별자를 기록한다.

## 제한

약사 계정으로 로그인한 세션과 약사 주문 데이터는 검증하지 않았다. 따라서 세 역할의 production 운영을 뜻하는 `OPERATED`를 주장하지 않는다.
