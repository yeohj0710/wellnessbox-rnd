# OP-076 중대한 이상사례 발생 시 계획과 추가 추천을 즉시 중단한다.

## 무엇을 해결했는가

복용 뒤 이상사례가 보고됐는데도 유지나 재추천이 계속되는 문제를 막았다. 이 안전 요구에 따라 정책 표에서 이상사례 규칙의 우선순위가 가장 높으며, 다른 개선 점수나 입력 값이 함께 들어와도 중단·에스컬레이션을 먼저 선택한다.

## 어떻게 구현했는가

`BoundedAgent`는 `FOLLOWUP_ACTIVE`에서 `ESCALATED`로 이동한 뒤 즉시 `STOPPED`로 끝낸다. 기존 중대한 이상사례 경로는 추천 실행을 멈추고 연결된 후속 작업을 취소하며 긴급 약사 검토를 한 번 만든다. 새 정책은 이 안전 경계를 우회하지 않는다.

## 무엇으로 확인했는가

등록된 검증 증거 `wellnessbox-rnd/data/original_plan/evidence/op075_op076_followup_input_serious_ae_smoke_v1.json`은 계획 중단, 후속 작업 취소, 추가 추천 차단, 긴급 검토 1건 생성을 확인한다. 새 정책 테스트 13개에서도 이상사례 입력은 모두 `stop_and_escalate`를 선택했다.

## 어디까지 믿을 수 있는가

로컬 트랜잭션과 재시도 경계는 검증됐다. 실제 임상 이상사례 대응이나 약사의 운영 판단을 대신하지는 않는다. 운영 전에는 `IMPLEMENTED`만 주장하고, 실제 검토 기록은 H-003과 H-007에서 남긴다.
