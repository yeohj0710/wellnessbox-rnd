# OP-034 질환별 금기와 검토 필요 규칙을 확대한다.

manifest가 가리키는 `wellnessbox-rnd/data/rules/safety_rules.json`에는 신장질환, 중증 신장기능 저하, 간부전·간경변, 혈색소침착증을 서로 다른 규칙으로 둔다. 질환명이 일치했을 때 제외할 성분과 자동 추천을 막을지 여부를 한 가지 상태로 뭉개지 않는 것이 이번 구현의 핵심이다.

## 질환마다 같은 조치를 쓰면 생기는 문제

모든 질환을 곧바로 전체 차단하면 위험 성분만 제외해도 되는 경우까지 추천을 멈춘다. 반대로 모두 경고로만 처리하면 자동화 범위 밖의 중증 상태에서도 계획을 시작할 수 있다. 이 연구는 질환 규칙에 `contraindication` 또는 `review_required`라는 효과를 기록하고, 별도의 심각도로 최종 상태를 결정하도록 나눴다.

현재 자료에서 만성 신장질환과 신장질환은 마그네슘 글리시네이트를 제외하고 검토 필요 상태가 된다. 신부전과 투석은 같은 성분을 빼면서 자동 추천 전체를 차단한다. 간부전과 간경변은 특정 성분 하나로 위험을 좁히지 않고 전체 추천을 멈춘다. 혈색소침착증은 철과 비타민 C를 후보에서 제외한 뒤 검토가 필요하다고 표시한다.

## 규칙 효과와 심각도를 따로 읽은 결과

`wellnessbox-rnd/src/wellnessbox_rnd/domain/models.py`는 금기 규칙에 제외 성분이 하나도 없으면 자료를 거부한다. 다만 이 제약은 `effect=contraindication`에만 적용된다. 간 질환처럼 `review_required`이면서 전체 차단 등급을 가진 규칙은 특정 성분 목록 없이 자동 추천 전체를 중단할 수 있다.

최종 상태는 효과 이름만으로 정하지 않는다. `wellnessbox-rnd/src/wellnessbox_rnd/safety/service.py`는 적용된 규칙 중 blocker가 있으면 `blocked`, warning이 있으면 `needs_review`로 만든다. 그래서 혈색소침착증은 자료상 금기 효과지만 두 성분을 제외한 `needs_review`이고, 간 질환은 검토 필요 효과지만 전체 `blocked`다. 이 차이를 무시하고 “금기는 모두 차단, 검토 필요는 모두 경고”라고 요약하면 실제 동작과 어긋난다.

## 여덟 사례로 확인한 경계

`wellnessbox-rnd/tests/test_special_population_condition_safety.py`는 신장질환, 신부전, 간경변, 혈색소침착증을 각각 넣고 규칙 ID, 상태, 제외 성분을 비교한다. 계절성 알레르기처럼 등록되지 않은 질환은 아무 규칙도 적용하지 않아 과잉 일치를 막는다. 금기 규칙에 제외 성분이 없으면 자료 형식 검사(Pydantic)가 실패하는 시험도 있다.

정본 결과 `wellnessbox-rnd/data/original_plan/evidence/op033_op034_special_population_condition_safety_smoke_v1.json`에는 위 네 질환과 불일치 사례가 추천 경로와 재현 경로로 나란히 기록돼 있다. 신장질환은 검토, 신부전과 간 질환은 전체 차단, 혈색소침착증은 철·비타민 C 제외로 나타났다. 실패 발생 시점은 `확인되지 않음`으로 기록한다. 구현 전 처음 실패한 시험이나 오류 로그가 이 자료에 없기 때문이다. 최종 재발 방지 시험은 잘못된 심각도 통합과 미등록 질환의 오탐을 직접 겨냥한다.

## 현재 판단과 남은 검토

코드, 구조화 규칙, 자동 시험과 재현 가능한 정본 결과가 있으므로 OP-034의 단계는 `IMPLEMENTED`다. 정본 파일은 마그네슘과 철 관련 외부 자료 주소, 간 질환의 자동화 범위 제한을 정책 근거로 적는다. 그러나 규칙별 원문 구절과 승인 기록이 현재 manifest 증거에 모두 결합돼 있지는 않다. 질환 이름도 영문 표기 몇 가지에 한정되며 실제 진단 코드나 운영 사용자 자료를 시험하지 않았다. 이 결과를 전체 질환 안전 체계나 외부 검증 완료로 넓히지 않는다.
