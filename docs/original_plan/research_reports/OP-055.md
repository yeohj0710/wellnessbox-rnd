# OP-055 개인 개선도와 집단 평균 개선도를 분리한다.

## 개인 결과와 집단 결과가 섞일 때 생기는 문제

한 사람의 점수 변화와 여러 사람의 평균 변화는 답하는 질문이 다르다. 개인 결과는 특정 계획에서 그 사람의 복용 전후 상태가 어떻게 달라졌는지를 보여 준다. 집단 평균은 같은 조건으로 묶은 여러 개인 결과를 한데 모아 전체 관찰값의 경향을 나타낸다. 평균만 남기면 누가 얼마나 달라졌는지 사라지고, 개인 값을 집단 효과처럼 말하면 한 사례를 일반화하게 된다. OP-055는 두 결과를 한 문서 안에 두되 서로 다른 필드로 보존하도록 했다.

기준 계약 `wellnessbox-rnd/data/contracts/pro_group_effect_summary_v1.json`은 집계 단위를 `plan_linked_baseline_followup_pair`로 고정한다. 같은 계획 ID로 연결된 복용 전·후 한 쌍이 개인 효과 한 건이다. 집단 평균은 이 개인별 관찰 변화의 산술평균으로만 계산한다. 원래 설문 원점수를 먼저 모두 합쳐 하나의 가상 사용자를 만드는 방식은 사용하지 않는다.

## 분리 구조를 만든 방법

`src/wellnessbox_rnd/metrics/pro_group_effects.py`의 `PROGroupEffectSummaryV1`은 `personal_effects`와 `group_estimate`를 별도 필드로 가진다. 전자는 개인별 계획 ID, 복용 전·후 평가, 점수 변화, 순응도와 해석 상태를 그대로 담는다. 후자는 표본 수, 해석 가능한 개인 수, 상태별 건수, 건강 Z 점수 평균, 건강 백분위 변화 평균과 신뢰구간만 담는다. 집단 요약을 만든 뒤에도 개인 숫자를 다시 계산하거나 덮어쓰지 않는다.

집계 결과가 입력 순서에 좌우되지 않도록 개인 효과를 계획 ID로 정렬한다. 같은 계획이 두 번 들어오면 한 사람을 중복 집계할 수 있으므로 거부한다. 복용 후 시점이 서로 다르거나 자료 종류가 섞인 경우, 평가 ID가 중복된 경우도 한 집단으로 묶지 않는다. 설문명·채점 버전·시작 분포 지문이 모두 같은지 비교해, 다른 기준에서 나온 변화량을 평균내는 오류도 막는다.

## 잘못된 집계를 드러낸 시험

`tests/test_pro_group_effects.py`는 개인 세 건의 `mean_health_z_change`를 먼저 만들고, 집단 평균이 그 세 값의 산술평균과 같은지 비교한다. 같은 시험은 집단 요약의 `personal_effects`가 입력 개인 결과와 같고 `causal_effect_claim_allowed`가 항상 거짓인지도 본다. 집단 요약이 개인 결과를 정규화한다는 이유로 수치를 다시 쓰거나, 평균만 남기고 원자료를 버리면 이 시험을 통과하지 못한다.

오류 입력 시험은 중복 계획, 서로 다른 2주·4주 시점, 다른 시작 분포, 합성 자료와 실제 관찰 자료 혼합, 중복 평가 ID를 각각 거부한다. 계산된 집단 평균이나 불확실성 이유 코드를 사후에 바꾼 자료도 다시 검증할 때 실패한다. 방어 로직이 생기기 전의 구체적인 장애와 수정 시점은 `확인되지 않음`으로 남긴다. 조사 범위는 등록된 집단 계약, 구현 파일, 시험과 기준 실행 증거였다. 현재 차단 조건과 회귀 시험은 잘못된 집계가 다시 허용되지 않는 경계를 보여 준다.

## 백 명 합성 집단의 검증 결과

기준 증거 `wellnessbox-rnd/data/original_plan/evidence/op055_op056_pro_personal_group_uncertainty_smoke_v1.json`은 계획 ID가 `plan_000`부터 `plan_099`까지인 개인 효과 100건을 사용했다. 개인 효과 목록의 내용 지문을 따로 기록하고, 집단 요약 전후의 개인 숫자가 변하지 않았는지 확인했다. 결과는 표본 수 100, 해석 가능한 개인 100, 건강 Z 점수 평균 변화 0.67, 건강 백분위 평균 변화 25.779542였다.

같은 100건을 역순으로 넣어도 결과가 같았고, 집단 평균은 개인 값의 산술평균과 일치했다. 보고서 재작성 과정에서 `tests/test_pro_group_effects.py`를 다시 실행해 전체 시험 통과도 확인했다. 이 검증은 개인 결과 보존과 집단 집계 분리가 코드에서 실제로 유지된다는 근거다. 다만 100건 모두 규칙으로 만든 합성 결과 대체 자료이며, 숫자가 실제 사용자 집단의 개선을 나타내지는 않는다.

## 완료 단계와 해석 범위

현재 단계는 `IMPLEMENTED`다. 개인별 관찰값과 집단 평균을 구조적으로 분리하고, 잘못 묶인 집단을 거부하며, 같은 입력에서 같은 집계가 나오는 기능까지 입증됐다. 서비스 연결이나 상용 운영 증거는 등록돼 있지 않다. 기준 증거도 `real_world_outcome_used=false`, `service_integration_proven=false`, `production_operation_proven=false`로 범위를 닫는다.

집단 평균이 양수라는 사실만으로 모든 개인이 좋아졌거나 추천 성분이 개선의 원인이라고 말할 수 없다. 현재 계약도 결과 범위를 원인이 확인되지 않은 집단 관찰 연관으로 제한한다. 다음 검증에서는 실제 관찰 자료를 동일한 시작 분포와 시점으로 묶고, 탈락자·누락 복용·이상사례가 포함된 개인 결과가 평균에서 사라지지 않는지 확인해야 한다.
