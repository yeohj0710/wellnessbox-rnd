# 사람 개입 일괄 처리 체크리스트

이 파일은 구현 중 사람 판단이 필요했던 지점을 모아두는 원장이다. Codex는 여기 항목을 추가하고 기본값(가정)으로 계속 진행한다. 사람은 마지막 최종 세션에서 이 목록만 보고 한 번에 처리한다. 형식: 결정 대상 / 택한 기본값 / 뒤집을 경우 고칠 것 / 완료 조건.

## 닫힌 항목
### H-002 다음 행동 정책 테이블의 의약학적 타당성
- 결정 대상: 상태×이벤트→액션 규칙(유지/재최적화/감량/교체/중단/에스컬레이션 기준, 점수 임계값).
- 택한 기본값: master_context 19.3 예시 의미를 따르되 안전 보수 원칙 적용 — 이상사례는 무조건 중단·에스컬레이션, 점수 악화는 재최적화, 모호하면 보류.
- 뒤집을 경우: 정책 파일 수정 + 영향받는 시나리오 재라벨 + 평가 재실행. 정책이 데이터 파일이므로 코드 수정은 불필요.
- 완료 조건: 자문약사가 정책 테이블을 읽고 승인. (최종 세션)

### H-003 AI 초안 데이터의 실제 약사 검토 세션
- 결정 대상: 생성된 초안 전체의 승인·수정·반려.
- 택한 기본값: 세션 전까지 실제 초안은 `pending`으로 유지한다. 시스템은 `pending`과 `rejected` 초안을 학습·평가·추천·지식 경로에서 차단하며, 시뮬레이션 데이터로 승인 경계를 검증했다.
- 뒤집을 경우: 해당 없음(대기 상태가 기본).
- 완료 조건: 과제 참여 예비 약사 검토 세션 1회(예상 1~2시간). 이후 승인 데이터로 학습·평가 사이클 1회 실행. (최종 세션) 2차년도 검토는 예비 약사 사전 검토이며, 3차년도에 면허 취득 뒤 같은 초안 판정을 약사 자격으로 재확인한다.

### H-004 재작성 보고서 톤 확인
- 결정 대상: STYLE_GUIDE 적용 결과가 오너가 원하는 문체인지.
- 택한 기본값: STYLE_GUIDE 그대로 적용해 전량 진행.
- 뒤집을 경우: 가이드 수정 후 문체만 일괄 재적용(사실·숫자 불변이므로 기계적 재작성).
- 완료 조건: 오너가 임의 2~3편을 읽고 승인. (최종 세션)

### H-005 OP-039 과제 참여 예비 약사 안전 검토
- 결정 대상: 과제 참여 예비 약사 권혁찬의 고위험 사례 10건 직접 판정과 서명.
- 자격 단계: 2026-07 현재 검토자 두 사람 모두 약사 면허를 받지 않았고 2027-01 취득 예정이다. 2차년도 검토는 예비 약사 사전 검토로 기록하며 "약사가 검토했다"고 쓰지 않는다. 면허 취득 뒤 3차년도에 같은 사례를 약사 자격으로 다시 검토한다. 자세한 내용은 `REVIEWER_QUALIFICATION_POLICY.md`를 따른다.
- 택한 기본값: 여형준의 기존 기록은 `self_review`로 보존하고 OP-039 EXTERNAL 근거에서 제외한다. 권혁찬은 구현 미참여·과제 공동연구원으로 기록하며 `independent_of_implementation_team=false`를 강제한다. 권혁찬은 H-003 초안도 검토하므로 `was_ai_draft_reviewer=true`로 기록되고 시스템 경고가 남는다.
- 뒤집을 경우: 해당 없음.
- 완료 조건: 권혁찬이 콘솔에서 이름과 소속을 입력하고 10개 사례를 각각 판정·서명한 결과를 등록한다. 면허 번호와 자격 확인 방법은 2차년도에 받지 않는다. 존재하지 않는 값이기 때문이다. 등록 뒤에도 `requires_licensed_reconfirmation=true`가 남으며 OP-039는 `EXTERNAL`로 올라가지 않는다.
- 입력 검증: 오너 본인과 시스템 계정은 이름을 정규화해 별칭까지 차단한다. 등록된 과제 참여자가 아니거나 소속이 등록 정보와 다르면 거부한다. H-003 초안 원장에 있는 사람이 `was_ai_draft_reviewer=false`로 신고하면 거부한다. `licensed_pharmacist` 주장도 현재 단계에서는 거부한다. 기존 판정을 새 검토자에게 복사하거나 미리 선택하지 않는다.

### H-006 최종 영수증 2종 등록
- 결정 대상: 전체 검증 영수증, 독립 검토 영수증(Ed25519 서명).
- 택한 기본값: 미등록 유지. 감사 결과 BLOCKED는 정상 상태로 취급.
- 뒤집을 경우: 해당 없음.
- 완료 조건: 서명 가능한 사람이 모여 영수증 생성·등록 → OP-120 감사 READY 확인. (최종 세션의 마지막 순서)

### H-007 운영 환경 설정
- 결정 대상: 지정 로컬 연구 운영 환경의 실제 사용 증거와 41개 OPERATED 요구사항 커버리지.
- 택한 기본값: 추가 유료 서버와 상시 실행을 사용하지 않는다. `wellnessbox-local-research-pc`에서 필요할 때만 서버를 켜고, 서명된 실제 사용 영수증만 OPERATED 근거로 인정한다.
- 뒤집을 경우: 다른 운영 환경을 지정하면 환경 문서, 영수증 환경 ID, 수집기 서명 정책, 41개 행동 매핑을 함께 고친다.
- 완료 조건: 설문·추천·후속평가·약사 검토의 실제 저장 변화가 담긴 서명 영수증이 누적되어 콘솔 H-007이 41/41을 표시한다.
- 2026-07-23 오너 결정 변경: 이 컴퓨터를 필요할 때만 사용하는 지정 로컬 연구 운영 환경으로 정의한다. 서버 시작만으로는 증거가 되지 않으며 실제 경로의 저장 변화가 있어야 한다. 리허설은 실제 영수증 경로를 건드리지 않는다.
- 2026-07-24 보강: H-007은 누적 유효 영수증 수와 영수증에 기록된 서로 다른 프로필 수를 함께 표시한다. 최소 5개 프로필은 사람이 연령·목표·복용약물을 다르게 입력해 전체 경로를 실제 실행해야 하며 자동 데이터 생성은 운영 증거로 인정하지 않는다.

### H-001 정렬 감사의 중대 어긋남 처리 방침
- 결정 대상: `plan_alignment_audit_2026-07-23.md`의 중대 어긋남 4건 처리.

- 완료 조건: 사용자가 2026-07-23 처리 방침을 승인했고, 130개 사례 정확도 100%와 유효 보고서 50→58 개선을 확인했다. 완료.
