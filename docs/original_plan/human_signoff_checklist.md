# 사람 개입 일괄 처리 체크리스트

이 파일은 구현 중 사람 판단이 필요했던 지점을 모아두는 원장이다. Codex는 여기 항목을 추가하고 기본값(가정)으로 계속 진행한다. 사람은 마지막 최종 세션에서 이 목록만 보고 한 번에 처리한다. 형식: 결정 대상 / 택한 기본값 / 뒤집을 경우 고칠 것 / 완료 조건.

## 열린 항목

### H-002 다음 행동 정책 테이블의 의약학적 타당성
- 결정 대상: 상태×이벤트→액션 규칙(유지/재최적화/감량/교체/중단/에스컬레이션 기준, 점수 임계값).
- 택한 기본값: master_context 19.3 예시 의미를 따르되 안전 보수 원칙 적용 — 이상사례는 무조건 중단·에스컬레이션, 점수 악화는 재최적화, 모호하면 보류.
- 뒤집을 경우: 정책 파일 수정 + 영향받는 시나리오 재라벨 + 평가 재실행. 정책이 데이터 파일이므로 코드 수정은 불필요.
- 완료 조건: 자문약사가 정책 테이블을 읽고 승인. (최종 세션)

### H-003 AI 초안 데이터의 실제 약사 검토 세션
- 결정 대상: 생성된 초안 전체의 승인·수정·반려.
- 택한 기본값: 세션 전까지 실제 초안은 `pending`으로 유지한다. 시스템은 `pending`과 `rejected` 초안을 학습·평가·추천·지식 경로에서 차단하며, 시뮬레이션 데이터로 승인 경계를 검증했다.
- 뒤집을 경우: 해당 없음(대기 상태가 기본).
- 완료 조건: 자문약사 검토 세션 1회(예상 1~2시간). 이후 승인 데이터로 학습·평가 사이클 1회 실행. (최종 세션)

### H-004 재작성 보고서 톤 확인
- 결정 대상: STYLE_GUIDE 적용 결과가 오너가 원하는 문체인지.
- 택한 기본값: STYLE_GUIDE 그대로 적용해 전량 진행.
- 뒤집을 경우: 가이드 수정 후 문체만 일괄 재적용(사실·숫자 불변이므로 기계적 재작성).
- 완료 조건: 오너가 임의 2~3편을 읽고 승인. (최종 세션)

### H-005 OP-039 독립 외부 고위험 검증
- 결정 대상: 외부 검증 주체 섭외와 실행.
- 택한 기본값: 미등록 상태를 사실대로 유지. manifest의 claimed_stage 공백도 그대로 둔다.
- 뒤집을 경우: 해당 없음.
- 완료 조건: 외부 검증 결과 등록. (최종 세션 또는 별도 일정)

### H-006 최종 영수증 2종 등록
- 결정 대상: 전체 검증 영수증, 독립 검토 영수증(Ed25519 서명).
- 택한 기본값: 미등록 유지. 감사 결과 BLOCKED는 정상 상태로 취급.
- 뒤집을 경우: 해당 없음.
- 완료 조건: 서명 가능한 사람이 모여 영수증 생성·등록 → OP-120 감사 READY 확인. (최종 세션의 마지막 순서)

### H-007 운영 환경 설정
- 결정 대상: Vercel 환경변수(WB_RND 계약), R&D API 배포, 운영 왕복 확인.
- 택한 기본값: 로컬 통합 증거까지만 만들고 `INTEGRATED`로 주장. `OPERATED` 주장 금지.
- 뒤집을 경우: 해당 없음.
- 완료 조건: 오너가 승인된 값으로 환경 설정 후 배포 식별자·health 확인. (최종 세션)

## 닫힌 항목

### H-001 정렬 감사의 중대 어긋남 처리 방침
- 결정 대상: `plan_alignment_audit_2026-07-23.md`의 중대 어긋남 4건 처리.
- 택한 기본값: 프로그램 문서의 확정 설계대로 `ClosedLoopState`/`BoundedAgent`에 후속 전이를 통합하고 선언적 정책 파일과 130개 평가 사례를 추가했다.
- 뒤집을 경우: 상태기계 통합 방향을 바꾸면 Phase 2 산출물 전체를 다시 작업한다.
- 완료 조건: 사용자가 2026-07-23 처리 방침을 승인했고, 130개 사례 정확도 100%와 유효 보고서 50→58 개선을 확인했다. 완료.
