# 로컬 연구 운영 세션 3일 절차

## 서버는 명령 하나로 켠다

PowerShell에서 아래 명령 한 줄을 실행한다. R&D API, 웰니스박스, 최종 세션 콘솔이 이 컴퓨터에서만 켜진다. 유료 서버와 상시 실행은 사용하지 않는다.

```powershell
C:\dev\wellnessbox-rnd\research-server-start.cmd
```

명령 창은 사용하는 동안 열어 둔다. 작업을 마치면 `C:\dev\wellnessbox-rnd\research-server-stop.cmd`를 실행한다. 서버가 종료될 때 실제 SQLite 저장 건수의 변화를 읽어 서명된 운영 영수증을 자동 생성한다.

## 1일차에는 설문과 추천을 실제로 사용한다

예상 시간은 10~15분이다. 최종 세션 콘솔 H-007에서 `설문·추천·후속평가 화면 열기`를 누른다. 연구용 사용자로 설문을 한 번 제출하고 추천을 요청한다. 안전 경고와 추천 근거를 읽은 뒤 결과를 저장한다. 이 행동은 프로필·동의·실행 이력·추천·안전 차단·서비스 왕복에 연결된 OP-021~030, OP-040, OP-071~072, OP-079~080, OP-096, OP-098~099, OP-101~102, OP-107~110, OP-117~118을 커버한다.

## 2일차에는 후속평가를 실제로 제출한다

예상 시간은 10분이다. H-007의 `설문·추천·후속평가 화면 열기`를 다시 누르고 1일차 추천에 연결된 후속평가로 이동한다. 복용 여부, 변화 점수, 부작용 유무를 입력한다. 악화 또는 부작용 사례는 실제 상황이 있을 때만 입력한다. 입력하지 않은 사실을 증거용으로 만들지 않는다. 후속평가가 저장되면 OP-053, OP-058, OP-073~078이 커버된다.

## 3일차에는 약사가 실제 검토를 한 건 처리한다

예상 시간은 10분이다. 자문약사가 H-007의 `약사 검토 화면 열기`를 누르고 실제 대기 초안 한 건을 승인·수정 승인·반려 중 하나로 결정한다. 대기 초안이 0건이면 운영 증거를 만들기 위해 임의 초안을 생성하지 않는다. 실제 초안이 생긴 날 다시 처리한다. 이 행동은 OP-087, OP-103~106을 커버한다.

## 41건이 모두 찼는지 확인한다

세 행동이 실제 저장된 뒤 최종 세션 콘솔 H-007에서 `운영 영수증 다시 확인`을 누른다. 화면이 `41/41개`를 표시해야 한다. 세 행동을 각각 한 번 완료할 수 있으면 보통 3일, 하루 10~15분이면 끝난다. 실제 후속평가나 약사 검토 대상이 늦게 생기면 필요한 날만 서버를 다시 켜고 이어서 사용한다. `41/41개` 전에는 OPERATED 완료로 기록하지 않는다.
