# 한 번에 마감하기

## 이것만 하면 된다

저장소 폴더에서 `research-complete.cmd` 를 더블클릭한다. 끝이다.

창이 열리면 단계마다 무엇을 해야 하는지 알려 주고, 필요한 화면을 자동으로 띄운다. 사람이 할 일을 마쳤으면 Enter만 누르면 된다. 자동으로 되는 단계는 알아서 돌아간다.

```
research-complete.cmd
```

지금 어디까지 왔는지만 보고 싶으면 아래처럼 실행한다. 아무것도 실행하지 않고 현재 상태만 읽는다.

```
research-complete.cmd --status
```

## 창에서 쓰는 키 세 개

| 키 | 뜻 |
|---|---|
| Enter | 이 단계를 끝냈다. 실제로 저장됐는지 확인한 뒤 다음으로 넘어간다 |
| s | 이 단계는 나중에 한다. 건너뛰고 다음으로 간다 |
| q | 오늘은 여기까지. 다음에 같은 명령을 실행하면 이어서 진행한다 |

Enter를 눌러도 저장이 확인되지 않으면 넘어가지 않는다. 무엇이 빠졌는지 알려 주므로 화면에서 마저 처리하고 다시 Enter를 누르면 된다.

## 전체 12단계

| 순서 | 단계 | 누가 |
|---:|---|---|
| 1 | 사전 점검 | 자동 |
| 2 | 연구 서버 켜기 | 사람 |
| 3 | 실제 프로필 5건 입력 | 사람 |
| 4 | AI 초안 전수 검토 | 사람 |
| 5 | 승인 전용 데이터셋 만들기 | 자동 |
| 6 | 후보 모델 학습 | 자동(게이트가 열렸을 때만) |
| 7 | 안전 회귀 확인과 교체 판정 | 자동(후보 모델이 있을 때만) |
| 8 | 정책 9개 규칙 확인 | 사람 |
| 9 | 보고서 문체 승인 | 사람 |
| 10 | 고위험 10건 검토 | 사람 |
| 11 | 최종 영수증 2종 발급 | 사람 |
| 12 | 최종 감사 | 자동 |

6번과 7번은 학습 게이트가 아직 NO-GO다. 이 상태에서는 훈련하지 않고 실행 계획만 남긴 뒤 `[-]` 표시로 넘어간다. 실패가 아니라 정상이다.

## 과거 기록은 세지 않는다

실행기는 시작할 때 세션 시작 시각을 기록한다. 그 시각 **이전에** 저장된 완료 기록은 이번 세션 근거로 세지 않는다.

2026-07-23~24 세션에서 H-002부터 H-007까지 완료로 저장된 기록이 남아 있다. 그 값들은 화면에 `이번 세션 시작 전입니다`로 표시되고 다시 하라고 안내한다. 과거 상태를 새 판단으로 재사용하지 않기 위한 장치이며, 기존 기록을 지우지도 않는다.

프로필과 초안도 마찬가지다. DB에 이전 세션 프로필 5건이 있어도 이번 세션 몫은 0건부터 센다.

H-005는 하나 더 본다. 저장된 검토에 자격 단계 표시가 없으면 중립 화면 이전 기록이므로 다시 검토하라고 알려 준다.

## 실행기가 하지 않는 일

- 판정을 대신 고르거나 의견을 채우지 않는다. 사람이 화면에서 직접 해야 한다.
- 완료로 표시만 하고 넘어가지 않는다. 저장소를 다시 읽어 실제 저장을 확인한다.
- 학습 게이트가 닫혀 있으면 훈련하지 않는다.
- push, 배포, 영수증 위조를 하지 않는다.
- 운영 DB에 쓰지 않는다. 확인은 모두 읽기 전용이다.

## 중간에 멈췄다면

같은 명령을 다시 실행하면 된다. 진행 기록은 `artifacts/final_session/completion_wizard_progress_v1.json` 에 남고, 세션 시작 시각도 여기서 이어받는다.

처음부터 새 세션으로 시작하려면 `--new-session` 을 붙인다. 이때부터 그 이전 기록은 모두 과거 기록으로 취급된다.

```
research-complete.cmd --new-session
```

## 화면이 안 열릴 때

`--no-open` 을 붙이면 자동으로 열지 않는다. 주소를 직접 입력해서 열면 된다.

| 화면 | 주소 |
|---|---|
| 최종 확인 콘솔 | http://127.0.0.1:8765/ |
| 고위험 10건 검토 | http://127.0.0.1:8765/op039-review |
| 사용자 화면 | http://127.0.0.1:3001/research-login?redirect=/tips |
| 약사 화면 | http://127.0.0.1:3001/research-login?redirect=/pharm/tips |

## 이번 범위는 어디까지인가

2차년도에는 연구를 완료할 의무가 없다. 10번 고위험 검토는 **예비 약사 사전 검토**로 기록된다. 면허를 받는 3차년도에 같은 사례를 약사 자격으로 다시 검토해야 최종 근거가 된다. 자세한 내용은 `REVIEWER_QUALIFICATION_POLICY.md` 를 본다.

단계별 상세 절차와 실패 대응은 `FINAL_SESSION_RUNBOOK.md` 에 있다. 이 문서는 그 실행서를 순서대로 자동화한 것이다.
