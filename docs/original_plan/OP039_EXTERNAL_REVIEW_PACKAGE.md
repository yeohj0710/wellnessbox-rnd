# OP-039 독립 외부 고위험 검증 안내

## 검토자는 무엇을 확인하는가

외부 약사는 10개 고위험 사례의 입력, 시스템 최종 판정, 적용 규칙을 읽고 판정이 의약학적으로 타당한지 표시한다. 사례는 금기·특수집단 5건, 약물 상호작용 2건, 용량 초과 1건, 응급 신호 2건이다. 모든 값은 기존 시스템 smoke 결과에서 가져왔고 출처 증거 경로를 사례마다 적었다.

## 누가 검토할 수 있는가

검토자는 웰니스박스 구현팀과 독립된 외부 약사여야 한다. AI 초안을 검토한 약사와 같은 사람도 사용할 수 없다. 검토자는 소속, 약사 면허 식별정보, 성명, 검토 시각을 입력하고 독립성 문구에 동의한 뒤 성명을 다시 입력해 서명한다.

## 어떻게 제출하는가

최종 세션 콘솔 H-005에서 `미리 채운 외부 검토 화면 열기`를 누른다. 시스템은 모든 사례에 `타당` 권장안을 미리 표시한다. 외부 약사는 근거를 읽고 다른 사례만 `부적절`로 바꾸며, 그 경우 이유를 쓴다. 성명·소속·약사 면허 식별정보와 독립성 확인을 입력한 뒤 `내 이름으로 검토 확정 및 자동 등록`을 누른다. 입력한 성명은 전자서명으로 기록된다. 콘솔은 사례 누락, 내부 검토자 사용, 원본 사례 지문 불일치를 거부한다.

## 언제 완료로 인정하는가

10건이 모두 타당하다고 판정되고 검토자 정보와 서명이 유효하면 OP-039 외부 증거로 등록한다. 한 건이라도 부적절하면 결과는 사실대로 저장하지만 OP-039를 완료로 올리지 않는다. 시스템 판정을 고친 뒤 새 패키지로 다시 검토해야 한다.
